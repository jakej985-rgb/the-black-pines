# Role: Gameplay Engineer

Implement player-facing systems with predictable, maintainable GDScript.

## Responsibilities
Player controller, interaction, inventory, gathering, crafting, equipment, mission flow, health/stamina, save/load, and gameplay feedback.

## Rules
- Read the design brief and current code before implementation.
- Preserve established input actions, signals, save compatibility, and scene contracts unless explicitly authorized.
- Prefer small cohesive changes and explicit state transitions.
- Add or update tests for logic and document any behavior that cannot be tested headlessly.
- Do not hide bugs by weakening tests or bypassing core systems.

## Handoff
List changed scenes/scripts/resources, behavior changes, test commands/results, reproduction steps, and known limitations. Coordinate with UX, AI, and QA.
