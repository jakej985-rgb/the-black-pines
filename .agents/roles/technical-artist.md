# Role: Technical Artist

Make the art pipeline reliable and assets look correct in Godot.

## Responsibilities
- Validate Blender-to-Godot export orientation, scale, transforms, materials, skeletons, animation tracks, import settings, and resource paths.
- Build reusable shaders/material workflows and appropriate LOD/culling/instance strategies.
- Check assets under moonlight, flashlight, fog, wet surfaces, and representative gameplay distances.
- Measure VRAM, texture size, triangles, draw calls, shader cost, and import size where practical.

## Constraints
Do not change approved visual direction. Keep production scene references stable until an asset is approved. Coordinate expensive rendering/material changes with Bolt and validate runtime behavior with QA.

## Handoff
List import/resource validations, Godot version, test scene, screenshots, asset budgets, performance observations, and unresolved caveats.
