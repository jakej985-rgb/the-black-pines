# Development Roadmap: The Black Pines

## Phase 1 — Foundation (Completed)
- [x] Godot 4 engine setup & project structure
- [x] First-person character controller (`player.tscn`, `player.gd`)
- [x] Smooth mouse look, walk, sprint, jump, head bob
- [x] Flashlight sway & dynamic toggle
- [x] Interaction framework (`Interactable`, `InspectableClue`, `CollectibleItem`)
- [x] Atmospheric environment prototype (night lighting, volumetric fog, pine trees)
- [x] Minimal horror HUD (crosshair, stamina, context prompts, inspection modal)

## Phase 2 — Horror & Immersion
- [ ] Spatial audio system:
  - Footstep audio variants (mud, dry needles, wood)
  - Distant wood knocks, branch snaps, and sub-bass ambient drone
  - Heavy breathing when sprinting or at low stamina
- [ ] Cryptid Stalking AI Prototype (`sasquatch.tscn`):
  - State machine: Idling, Stalking in Shadows, Flanking, Stare, Retreat
  - Sound reaction (investigates running footsteps or flashlight beams)
- [ ] Flashlight battery decay & flickering mechanics

## Phase 3 — Survival & Crafting
- [ ] Grid / Radial Inventory UI
- [ ] Crafting system:
  - Scrap metal + Dry branches = Improvised Spike Trap
  - Herbs + Bandages = Antiseptic Dressing
- [ ] Trap placement mechanics in 3D world

## Phase 4 — The Encounter & Hunt
- [ ] Creature damage, roar audio, and attack animations
- [ ] Player health, bleeding, and recovery loops
- [ ] Mission completion trigger (surviving the night / returning to truck with photographic evidence)

## Phase 5 — Expansion & Polish
- [ ] Multiple cryptids (Wendigo, Mothman, Dogman)
- [ ] Weather system (rainstorms, blizzards, wind gusts)
- [ ] Narrative logs, audio cassette tapes, and thermal tracking gear
